            Explainability

            How the Models Decide

            Interactive visualization demonstrating K-Nearest Neighbours distance calculations and Random Forest ensemble voting.

            Live KNN Exploration

            —

            Drag the point: distance reflects normalized categorical variations and standardized budget/duration variance.

            Euclidean Distance Metric

            d(q, p) = √ Σᵢ (qᵢ − pᵢ)²  across 81 one-hot & scaled dimensions

            K-Nearest Neighbours

            Instance-Based
            1. One-hot encode categories and standard-scale numeric features.
            2. Compute Euclidean distance across all 560 training projects.
            3. Select the K closest historic work records.
            4. Aggregate class votes (majority decision rule).
            5. Compute risk probability as the fraction of overrunning neighbours.

            Highly explainable decision path; training dataset serves directly as the reference space.

            Random Forest

            Winning Model
            1. Construct 300 decision trees via bootstrap aggregation.
            2. Partition nodes on optimal Gini impurity reductions.
            3. Average probabilistic outputs across all 300 estimators.
            4. Apply balanced class weighting to handle overrun rarity.

            Captures non-linear thresholds on money and time; delivers superior test recall (84.8%).

            Technical Briefing

            Methodology & Architecture

            Comprehensive technical summary covering data processing, empirical findings, and operational limitations.

            Methodology

            Pipeline
            • Feature Processing: 6 attributes (scheme, state, district, execution, budget, duration) transformed into 81 numeric dimensions via OneHotEncoder and StandardScaler.
            • Partitioning: Stratified 80/20 train/test split (seed 42) guaranteeing exactly 42% overrun target distribution across both sets.
            • Evaluation Rule: Overrun F1 score serves as the primary selection criterion, preventing majority-class accuracy distortion.

            Empirical Findings

            Key Insights
            • Execution Agency: Dominant feature (50.8% Random Forest importance); departmental packages exhibit higher escalation rates.
            • Scale Sensitivity: Smaller sanctioned budgets experience greater percentage slippage due to fixed overheads.
            • Schedule Duration: Multi-year works carry cumulative exposure to material price escalations and revisions.

            Limitations

            Scope Constraints
            • Synthetically generated project dataset calibrated on public CAG audit trends.
            • Feature set omits statutory clearance milestones, land acquisition, and monsoon calendars.
            • Expected expenditure uses a calibrated scheme heuristic rather than a standalone regressor.

            Future Scope

            Roadmap
            • Automated data pipelines ingesting state e-procurement tender registries.
            • Gradient boosting benchmarks (XGBoost/LightGBM) with per-scheme class tuning.
            • Direct multi-target regression predicting both probability and rupee overrun amount.
